# Security policy

## Supported versions

Only the latest minpdf release receives security fixes.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in an issue, discussion, or pull request. Submit them through [GitHub private vulnerability reporting](https://github.com/actiledev/minpdf/security/advisories/new).

Please include:

- The affected version, binding, runtime, and operating system
- The expected impact and conditions required to trigger the issue
- A minimal reproducer, relevant logs, or sanitizer output
- A suggested mitigation, if available

Maintainers will investigate through the private advisory and coordinate a fix and disclosure when practical. Ordinary bugs without a security impact belong in the public [issue tracker](https://github.com/actiledev/minpdf/issues).
